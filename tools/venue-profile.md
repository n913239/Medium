# Venue profile — Claude Code 中英雙語系列

給校稿工具看的「這個場域長什麼樣」。跑 sepia、humanizer 或任何去 AI 味的工具之前，
先讓它讀這份，否則它會把**體例**當成 AI 痕跡標出來。

sepia 的 `SKILL.md` 有一段 "Read the venue first"：動筆或改稿前先取樣 2–3 篇同場域的
人類稿件，照那個 register 改；它明說**場域語料定義目標，不是規則書定義**。這份檔案就是
那個取樣的結果，寫成文字，省得每次重讀。

> 這是 venue profile（場域體例），不是 persona（作者聲音）。
> 真要寫 persona，用 sepia 的 `references/voices/PERSONA-TEMPLATE.md`，那是另一回事：
> 它描述的是作者對讀者的姿態、第一句做什麼、溫度與判斷怎麼並行，得訪談本人才寫得出來。

## 場域

- Medium，`@n913239`，Claude Code 系列，每週一篇，中英雙語各一版，結構一一對應
- 讀者：寫程式的人，多半也在用 Claude Code 或考慮要用
- 文類：sepia 路由走 **technical articles**（`domains/tech-articles.md`）
- 數值基準不寫在這裡 —— `medium-check` 的 `check_rhythm` 會從 `story/` 底下已發布的文章
  現算句長中位數。基準會自己跟著系列長，寫死在檔案裡只會過期

## 這些是體例，不要標

| 形式 | 說明 | 會被誤判成 |
|---|---|---|
| `## 總結` / `## Summary` 收尾，重述前面的發現 | CLAUDE.md 明定的固定結尾 | sepia check 7 conclusion residue |
| `## 參考資料` / `## References` | 同上 | 同上 |
| 每個 H2 前一條 `---` | 版面慣例，Medium 上是分隔線 | — |
| 破折號「——」用得兇（系列約 300–400 / 10 萬字） | 作者既定風格。sepia 自己的語料也支持：台灣新聞 61% 的文章在用，三個 2026 模型幾乎不用 | humanizer §14 em dash |
| 粗體標重點，一段內可能三四處 | 既定風格。只有「整句都粗體」或「一段超過五處」才值得提 | humanizer §15、sepia check 6 |
| `>` 引言塊放金句 | 刻意的節奏設計 | — |
| 狀態 emoji（🔴🟡✅⚠） | 筆記與表格的狀態欄慣例，不出現在正文敘述裡 | humanizer §18、sepia check 6 |

| 中英文之間一個半形空格 | 排版慣例 | — |
| 「問題 → 做法 → 數字 → 這個實驗沒告訴你的事」 | 文章骨架 | sepia 的 QUD linear interview |

## 這些是真的要標

- **「不是 X，而是 Y」**：一次是正常，一篇出現兩次以上要挑一個留下。
  兩套工具都抓這條，sepia 的語料顯示機器用量是人類的 3–7 倍
- **conclusion residue 的真正形態**：不是「有總結這一節」，而是總結裡**只有重述、沒有新判斷**。
  收在一個具體數字或一個沒解決的問題上就是好的
- **節奏平板**：連續三句長度相近。交給 `check_rhythm` 量，系列中位數是每百句 2–4 次
- **英文版的短句病**：41+ 詞長句佔比長期在 0–5%，`because` 用量常常是個位數。
  這不是 AI 腔，是單調 —— 但 2026-09 英文版被留言批 AI 腔那次，單調也在症狀裡
- **假的坦白鉤子、預告下一段、回答沒人提的反對**：中文版偶爾會冒出來
- **數字沒有條件**：版本號、日期、跑幾次、什麼機器 —— 少一個就是 tell

## 不可動的東西

- **數字一律真實值**：行數、tool call 次數、token 數、距離值。那是文章可信度的來源，
  也是去識別化刻意保留的部分（數字不具識別性）
- **類別名是 stand-in，跨篇一致**：換過的名字不要再換回去，也不要「順手改得更自然」。
  對照表在 CLAUDE.md，實際樣式在 `tools/mcp/medium-check/deident-patterns.txt`（不進版控）
- **程式碼區塊、JSON、指令**：原樣，不潤飾
- **引用與站內連結**：中英各自指向對應語言版本，網址不動

## 英文版另外兩條

1. **不要逐句翻中文的修辭。** 英文版直接用平實英文寫。
   中文的對仗、排比、四字詞搬到英文就是 AI 腔
2. **humanizer（英文上游版）預設會直接改檔。** 要它只診斷，得明講。
