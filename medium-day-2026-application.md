## 演講準備計畫(NativeCamp 等級 7)

NativeCamp 等級 7 ≈ CEFR B1+/B2(中高級)。**背熟的 slide-driven 演講綽綽有餘;Q&A 是真正的考試。** 策略分兩塊。

### 🎤 30 分鐘主講部分(強項)

1. **全程逐字稿,背到熟,然後再演練** — 不要即興。等級 7 的人即興會抖
2. **語速慢、清楚就好** — 目標 110–120 字/分鐘(母語人士 150+)。Clarity beats fluency
3. **Slides 當 teleprompter 用** — 每張投影片放 3–5 個 keyword bullet,看到 keyword 觸發背好的句子
4. **簡化句型** — 等級 7 用複雜句容易卡。改用短句:Subject + Verb + Object
   - 不要說 "the infrastructure that I configured" → 改成 "the setup I built"
5. **30 分鐘 ≈ 3,000–3,500 字** — 用 Word 計字數,寫滿就剛好
6. **錄影自己練 5 遍** — 看回放找會絆到舌頭的字,替換成發得順的同義字

### 💬 Q&A 部分(難關)

7. **預先寫好 15 個常見問題的英文回答** — 涵蓋:
   - "How is this different from GitHub Copilot?"
   - "Do you trust the AI's code?"
   - "What about security concerns?"
   - "How long did it take to set up?"
   - "What about non-iOS developers?"
   - 等等

8. **準備三句萬用救命話** — 背到反射:
   - "That's a great question. Let me think about it for a second." (爭取 3 秒思考)
   - "Could you rephrase that? I want to make sure I understand." (聽不懂時)
   - "I don't have data on that, but my experience has been..." (不知道時)

9. **跟主辦方申請:Q&A 用 Zoom chat 文字提問** — 多數活動會配合,對 ESL 講者是很合理的請求

10. **找一個英文好的朋友模擬 Q&A** — 至少跑 3 次,讓他亂問刁鑽問題

### 加碼小撇步

- **演講前喝水**,中間停頓時喝一口 = 自然爭取思考時間
- **講台旁邊放小紙條** 寫 3 句最容易忘的關鍵句
- **錄影留底**:之後可以剪 1 分鐘 highlight 放履歷/Medium,免費的長期資產
- **演講前一晚睡飽** — 比練第 11 次有用十倍

### 結論

等級 7 + 4 個月準備 + 背熟逐字稿 + 投影片支撐 = **完全做得到**。

Q&A 是 risk,但用「文字提問 + 預備答案 + 救命話」三層防護就能 manage。內容深度是 unfair advantage — 觀眾原諒 ESL 口音,不原諒空話。
